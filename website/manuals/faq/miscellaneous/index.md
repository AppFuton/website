# Miscellaneous

Moments that can be useful, but not often.

## How do I pause reading history?

Enable Incognito mode by going to the main menu (three dots).

## What is DNS over HTTPS?

**DNS over HTTPS** (in Network settings) offers secure DNS resolution through HTTPS, preventing attacks. This may help bypass some basic website blocking.
