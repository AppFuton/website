# Sources

Frequently Asked Questions about Sources.

## How do I find and enable sources?

1. Go to Explore → Catalog
2. Browse available sources by language
3. Tap to enable the sources you want

## Why is a source not working?

Sources may go down or change their structure. Try:

1. Updating the app to the latest version
2. Checking if the source website is accessible in a browser
3. Using an alternative source for the same content

## Can I add custom sources?

Custom sources can be added through the parsers system. Check the [futon-parsers](https://github.com/AppFuton/futon-parsers) repository for more information.
